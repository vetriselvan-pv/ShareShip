# Build, Serve & Testing Execution Policy

1. Do NOT trigger any build command (`npm run build`, `ng build`, `tsc`, etc.) until the user explicitly confirms or requests it.
2. Do NOT serve any application (`npm start`, `npm run dev`, `ng serve`, `node`, dev servers, etc.) until the user explicitly confirms or requests it.
3. Do NOT perform any automated testing, browser subagents, or test runs until the user explicitly confirms or requests it.
